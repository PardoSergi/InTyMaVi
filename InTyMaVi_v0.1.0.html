Import from Grambank

Pick any grammatical feature(s) from Grambank to add to the map. If your currently loaded data already has a column named exactly like a Grambank code (e.g. GB130), the two are merged into that same feature so you can compare your own coding against Grambank's worldwide sample. Otherwise the feature is added as a new column. Languages you already have are never duplicated or overwritten.
